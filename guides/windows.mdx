A window holds tabs; tabs hold controls or groupboxes. Full option list: [Window options](/reference/window-options).

```lua
local window = Fire:Window({ Text = "My Interface", Keybind = Enum.KeyCode.RightShift })

window:AddHeader({ Text = "General" })
local main = window:AddTab("Main", { Text = "Main", Icon = "Home" })
window:AddSeparator()

local left = main:AddLeftGroupbox("Left", { Text = "Left" })
local right = main:AddRightGroupbox("Right", { Text = "Right" })
```

## Tab list

`AddTab`, `AddCustomTab`, `AddHeader`, `AddSeparator`.

## Groupboxes

`AddGroupbox`, `AddLeftGroupbox`, `AddRightGroupbox`. Tabs also accept controls directly.

## Navigation and visibility

| Method | Effect |
| --- | --- |
| `tab:SwitchTo()` | Select a tab |
| `window:SetTab(flag)`, `SetTab(tab)`, `SetTab(nil)` | Select or clear the tab |
| `Show()`, `Hide()`, `Toggle()` | Visibility |
| `TryClose()` | Close with confirmation |
| `Close()` | Close immediately |

<Warning>
  `Close()` resets every control to its default through `:Set`, so callbacks fire. Make callbacks that start work also handle shutdown. Closing doesn't unload library-wide loops or globals.
</Warning>
