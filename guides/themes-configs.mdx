The window ships with built-in Theme and Config settings pages. You can also drive them from code.

## Themes

A theme has four colors: `Main`, `Back`, `Stroke`, `Text`.

```lua
window.Options.Theme.Main = Color3.fromRGB(255, 90, 80)
window:Refresh()
```

### Premade themes

On first run the library writes these to `FireLibrary/Themes/`: Default, Ambience, Royalty, Emo, Emo 2, Anime, Anime 2 (My Favorite), (Light) Kawaii, Galaxy, Ketamine UI, Vampires, Menthol, Privacy. Restore them anytime from **Theme Settings → Restore Default Themes**. Without file functions they're still selectable from the Premade Themes dropdown.

## Share strings

```lua
local configString = window:GetConfigString()
local decoded, applied = window:SetConfigString(configString)

local themeString = window:GetThemeString()
local themeDecoded, themeApplied = window:SetThemeString(themeString)
```

The two booleans tell decoding apart from applying. `GetConfig` / `SetConfig` and `GetTheme` / `SetTheme` work with raw tables instead. Applying a config fires control callbacks.

## Saving to disk

Requires **all** of `writefile`, `readfile`, `delfile` (or `deletefile`), `makefolder`, `listfiles`, `isfolder`, `isfile`.

| Path | Contents |
| --- | --- |
| `FireLibrary/Configs/` | Saved configs (`.shrimp`) |
| `FireLibrary/Themes/` | Saved themes (`.shrimp`) |
| `FireLibrary/Cache/` | Downloaded assets |

Names must be 1 to 32 characters, without `/` or `\`. Share strings don't need file APIs.
