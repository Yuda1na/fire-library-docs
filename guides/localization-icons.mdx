## Translations

Pass `Translations` keyed by language. A string replaces `Text`; a table sets named fields.

```lua
tab:AddButton({ Text = "Save", Translations = { EN = "Save", RU = "Сохранить" } })
```

The window `Language` is normalized to two uppercase letters (`"ru"` becomes `"RU"`).

## Icons

`Icon` accepts:

- Built-in names: `Home`, `Cog`, `Save`, `Trash`, ...
- Lucide names: `l://circle-arrow-left`
- Asset IDs: `123456` or `rbxassetid://123456`
- Image URLs (downloaded and cached; needs file and asset APIs)
