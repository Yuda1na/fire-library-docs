---
title: "Keybind"
description: "Add a key selector and handle key presses."
icon: "command"
---

`AddKeybind` and `AddInput` are aliases. Desktop only: hidden on mobile.

```lua
box:AddInput("ActionKey", {
    Text = "Action key", Value = Enum.KeyCode.K,
    KeySet = function(key) print("key:", key) end,
    Callback = function(control) print("pressed") end,
})
```

| Option | Purpose |
| --- | --- |
| `Value` | Starting `Enum.KeyCode` |
| `KeySet` | Runs when the user picks a key. Receives `Enum.KeyCode` or `nil`. |
| `Callback` | Runs when the bound key is pressed |

Values are stored as numeric key codes or `false`.

Buttons and toggles also get an attached keybind used by the built-in keybind-editing mode. It behaves differently from a standalone keybind.
