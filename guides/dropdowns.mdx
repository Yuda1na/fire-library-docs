---
title: "Dropdown"
description: "Single and multi-select lists."
icon: "list"
---

<Warning>
  Use `Values`, not `Options`. The library's bundled example is wrong; the implementation reads `Values` (or the deprecated `Variants`).
</Warning>

```lua
local mode = box:AddDropdown("Mode", {
    Text = "Mode",
    Values = { "Low", "Normal", "High" },
    Value = 2,
    Callback = function(value, raw, control)
        print(value, raw)
    end,
})
mode:Set(3)
mode.Values = { "Slow", "Fast" }
```

## Callback arguments

| Mode | `Convert = true` (default) | `Convert = false` |
| --- | --- | --- |
| Single | `value, index, control` | `index, value, control` |
| Multi | `{ [value] = bool }, indexList, control` | `indexList, { [value] = bool }, control` |

`Value` stores an index, an index list, or `false`. `AllowUnselect` lets single-select clear the choice. Avoid duplicate entries in `Values`.
