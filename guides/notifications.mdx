---
title: "Notifications and labels"
description: "Show messages, prompts and floating labels."
---

```lua
window:Notification({ Title = "Ready", Text = "loaded", Duration = 4, Side = "Right" })
local yes = window:WindowNotification({ Title = "Confirm", Text = "Continue?", HasButtons = true })

local label = window:FloatingLabel("Status", { Title = "Status", Text = "ready" })
label.Text = "running"
label:Destroy()
```

`Notify` aliases `Notification`. A notification without `HasButtons` runs asynchronously and has its duration clamped to 2–120 seconds. With `HasButtons = true`, it waits for a response or timeout and returns a boolean. `HasButton` shows one button, but the normal call still runs asynchronously. `WindowNotification`/`InWindowNotification` waits and returns a choice when `HasButtons` is true. `SmartNotification` chooses the in-window or toast path based on visibility.

`NeverShowAgainFlag` is supported by in-window notifications. In this revision, selecting that option stores `false`, regardless of the chosen dialog button; verify the behavior you want before using it.
