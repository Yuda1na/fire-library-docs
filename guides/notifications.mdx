---
title: "Notifications and labels"
description: "Show messages, prompts and floating labels."
icon: "bell"
---

Toasts, confirmation dialogs and floating status labels.

```lua
window:Notification({ Title = "Ready", Text = "Loaded", Duration = 4, Side = "Right" })
local yes = window:WindowNotification({ Title = "Confirm", Text = "Continue?", HasButtons = true })

local label = window:FloatingLabel("Status", { Title = "Status", Text = "ready" })
label.Text = "running"
label:Destroy()
```

| Method | Behavior |
| --- | --- |
| `Notification` / `Notify` | Toast. Async; `Duration` clamped to 2 to 120 s. With `HasButtons = true` it yields and returns a boolean. |
| `WindowNotification` / `InWindowNotification` | Dialog inside the window. Yields and returns the choice with `HasButtons = true`. |
| `SmartNotification` | Picks in-window or toast depending on window visibility |
| `FloatingLabel(flag, options)` | Draggable label. Update `.Text`, remove with `:Destroy()`. |

`HasButton` (singular) shows one button but doesn't yield.

<Warning>
  `NeverShowAgainFlag` stores `false` no matter which button is pressed.
</Warning>
