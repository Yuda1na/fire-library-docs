## Common options

| Option | Purpose |
| --- | --- |
| `Text` | Label |
| `Value` | Starting value. `Default` overrides it on creation. |
| `Callback` | Runs on change or click |
| `Visible`, `Disabled` | Visibility and interaction |
| `Tooltip`, `DisabledTooltip` | Hover text |
| `Order` | Position in the parent |
| `Translations` | Per-language text. See [Localization](/guides/localization-icons). |
| `NoConfigs` | Exclude from saved configs (attached keybinds still save) |

Every control also has `New...` and short-name aliases.
