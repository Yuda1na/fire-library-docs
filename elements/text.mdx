Static text and layout helpers.

```lua
local label = box:AddLabel({ Text = "Status: idle" })
label.Text = "Status: ready"
box:AddHeader({ Text = "Options" })
box:AddSeparator()
box:AddSeparator({ Invisible = true })
```

- **Label:** supports rich text. Update with `label.Text = "..."`.
- **Header:** section title in a tab or groupbox. `window:AddHeader` adds one to the tab list.
- **Separator:** a divider line. `Invisible = true` leaves a gap only.

All support `Visible` and `Order`.
