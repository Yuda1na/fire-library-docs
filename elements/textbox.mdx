---
title: "Text box"
description: "Read text typed by the user."
icon: "keyboard"
---

A text input. The callback runs on focus loss by default.

```lua
local input = box:AddTextBox("Message", {
    Text = "Message",
    PlaceholderText = "Type here",
    Value = "",
    Callback = function(text) print(text) end,
})
input:Set("hello")
```

| Option | Purpose |
| --- | --- |
| `Instant` | Fire on every change |
| `RequiresEnter` | Fire only on Enter. Ignored with `MultiLine`. |
| `MultiLine` | Multi-line input |
| `ValueUsesPlaceholder` | Pass the placeholder when empty |
| `Disabled`, `NoConfigs` | Lock editing, exclude from configs |

`:Set(text)` fires the callback on change.
