Picks a number between `Min` and `Max`.

```lua
local amount = box:AddSlider("Amount", {
    Text = "Amount",
    Min = 0, Max = 100, Step = 5, Value = 50,
    Format = "/",
    Callback = function(value) print(value) end,
})
amount:Set(75)
```

| Option | Purpose |
| --- | --- |
| `Min`, `Max` | Range. Aliases: `Minimum`, `Maximum`. Must differ. |
| `Step` | Increment. `0` is continuous. |
| `Format` | Display format string or function (see below) |
| `AllowSetValue` | Right-click or double-click to type a value |
| `BypassSetValue` | Typed values skip range and step checks |
| `Styled`, `Compact`, `ShowCompactValue` | Presentation |

## Formats

`.` `%` `.%` `.1%` `.2%` `/` `//` `/%` `a` `+` `$` `e` `x` `,`

- `.%` treats `1` as 100%. `%` shows the raw value with a percent sign.
- Some formats divide by `Max` or `Max - Min`.
- A function receives the slider and returns the display text.

<Warning>
  `:Set(value)` does not clamp. Validate external input yourself.
</Warning>
