---
title: "Toggle and checkbox"
description: "Store a true or false value."
icon: "toggle-on"
---

A boolean switch. `AddCheckBox` is the same control with checkbox styling.

```lua
local enabled = box:AddToggle("Enabled", {
    Text = "Enabled",
    Value = false,
    Callback = function(value)
        print("enabled:", value)
    end,
})

box:AddCheckBox("ShowHints", { Text = "Show hints", Value = false })
enabled:Set(true)
print(enabled.Value)
```

| Method | Behavior |
| --- | --- |
| `:Set(value)` | Sets the value, fires the callback on change |
| `:Toggle(value?, noCallback?)` | Flips or sets the state. `noCallback = true` skips the callback. |
| `:AddColorPicker(options)` | Attaches a [color picker](/elements/color-picker) |

Supports the [common options](/guides/controls#common-options).

<Warning>
  Closing the window resets every registered control to its initial value through `:Set`, so callbacks fire during close.
</Warning>
