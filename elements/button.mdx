---
title: "Button"
description: "Run an action when a button is clicked."
icon: "hand-pointer"
---

Runs `Callback` on click.

```lua
local button = box:AddButton("Refresh", {
    Text = "Refresh",
    Icon = "Repeat",
    Tooltip = "Refresh the list",
    Callback = function(button)
        print("clicked")
    end,
})

button.Disabled = true
button.Text = "Unavailable"
```

| Option | Default | Purpose |
| --- | --- | --- |
| `Text` | `"Button"` | Label |
| `Callback` | function | Runs on click |
| `Icon` | `"Cursor"` | Icon name or asset |
| `Holdable` | `false` | Callback gets press and release |
| `Disabled`, `Visible` | `false`, `true` | Interaction and visibility |
| `Tooltip`, `DisabledTooltip` | `""` | Hover text |
| `RecolorIcon` | `true` | Tint icon with the theme |

With `Holdable = true` the callback receives `true` on press, `false` on release, then the control. Attach a [color picker](/elements/color-picker) with `button:AddColorPicker(options)`.
