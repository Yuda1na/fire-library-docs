# Fire Library documentation

Community-created Mintlify documentation for Fire Library, based on commit `2f57dd6de90b6d92525f6c8c3e4024f8d94e0dc2` (version 5.2.6). This project is not an official NullFire or Fire Library publication.

To preview, install Node.js 20.17 or newer (Mintlify does not support Node 25), then run `npx mint dev` from this directory. See the [Mintlify CLI documentation](https://mintlify.com/docs/cli) for current requirements.

The source is [Its-Kawi/Fire-Library](https://github.com/Its-Kawi/Fire-Library); consult its license when redistributing its code. Documentation examples have been reviewed against source but not live-tested across runtimes.
