---
title: "Key system"
description: "Display a client-side key prompt."
icon: "key"
---

Shows a key prompt and yields until the key is accepted or the window closes.

```lua
local accepted = window:KeySystem({
    KeyUrl = "https://example.com/key",
    Callback = function(key)
        return key == "example"
    end,
})

if not accepted then return end
```

| Option | Required | Purpose |
| --- | --- | --- |
| `KeyUrl` | Yes | Link shown to get a key |
| `Callback` | Yes | Returns `true` to accept the key |
| `Background`, `BackgroundImage` | No | Prompt background |

<Warning>
  Validation runs on the client. Anything checked in the callback can be bypassed.
</Warning>
