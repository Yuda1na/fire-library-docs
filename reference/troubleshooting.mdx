## `Invalid request return`

The official `Loader.lua` builds broken GitHub URLs. Use the direct loader in [Installation](/getting-started/installation).

## The window doesn't appear

- Check the first error in the console.
- Make sure the script runs on the client.
- Press the window keybind (default `LeftAlt`).
- `Fire:Window()` yields on settings init; if that errors, nothing returns.

## Dropdown shows the wrong choices

Use `Values`, not `Options`. See [Dropdown](/guides/dropdowns).

## Configs don't save

Your executor is missing a file function. See the list in [Themes and configs](/guides/themes-configs#saving-to-disk).

## `type(Fire)` isn't `table`

Expected. The library returns userdata proxies. See [Objects and flags](/getting-started/objects#proxies).
