Known quirks in v5.2.6.

- `Fire:Window()` yields until the built-in settings finish loading. If that fails, it never returns.
- The library overwrites `getfenv().require` and caches helpers in globals.
- Shared GUI objects and frame/clock listeners persist. Closing a window is not a full unload.
- Blur and cursor helpers run every frame. Measure performance on low-end devices.
- Window `Size` exists but is unfinished.
- The upstream README says configs are "coming soon"; they already work.
- `KeySystem` is client-side only. See [Key system](/reference/key-system).
