After [installation](/getting-started/installation), with the library in `Fire`:

```lua
local window = Fire:Window({
    Text = "My Interface",
    Footer = "Settings",
    Keybind = Enum.KeyCode.RightShift,
})

local main = window:AddTab("Main", { Text = "Main", Icon = "Home" })
local general = main:AddLeftGroupbox("General", { Text = "General" })

general:AddButton({
    Text = "Test",
    Callback = function()
        window:Notification({ Title = "Ready", Text = "Button clicked", Duration = 4 })
    end,
})

general:AddSlider("Volume", {
    Text = "Volume", Min = 0, Max = 100, Step = 5, Value = 50,
    Callback = function(value) print("Volume:", value) end,
})
```

Press Right Shift to toggle the window.

## Structure

| Object | Holds |
| --- | --- |
| `Fire` | The library. Creates windows. |
| `window` | Tabs and global settings. |
| `tab` | Controls, or groupboxes that arrange them in columns. |
| groupbox | Controls. |

Keep a reference (`local amount = box:AddSlider(...)`) to update a control later. See [Objects and flags](/getting-started/objects).
