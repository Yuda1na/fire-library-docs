Fire Library is built for executor scripts: mod menus, admin panels, utility scripts.

## Load it

The official `Loader.lua` builds broken GitHub URLs and fails with `Invalid request return`. Load the pinned source directly instead:

```lua
local url = "https://raw.githubusercontent.com/Its-Kawi/Fire-Library/2f57dd6de90b6d92525f6c8c3e4024f8d94e0dc2/Files/Library.lua"
local src = game:HttpGet(url)
local stop = src:find(";", src:find("local", 1, true), true)

local Fire = loadstring(
    "local parent = nil" .. src:sub(stop + 1)
    .. "\nreturn require(obj:FindFirstChildOfClass(\"ModuleScript\"))"
)()
```

Requires `game:HttpGet` and `loadstring`. Saving configs and themes also needs the file functions listed in [Themes and configs](/guides/themes-configs#saving-to-disk).

<Accordion title="Embedding in your own game">
  Not the main use case, but supported upstream:

  1. Copy `Files/Library.lua` into a ModuleScript.
  2. Append this line at the very bottom:
     ```lua
     return require(obj:FindFirstChildOfClass("ModuleScript"))
     ```
  3. Require it from a LocalScript:
     ```lua
     local Fire = require(path.to.FireLibrary)
     ```

  Without file functions, the Config and Theme pages fall back to share strings only.
</Accordion>
