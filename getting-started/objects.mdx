Every creation method accepts `(options)` or `(flag, options)`. The flag is the control's ID inside its parent.

```lua
local window = Fire:Window({ Text = "Test", Keybind = Enum.KeyCode.RightShift })
local tab = window:AddTab("Main", { Text = "Main" })
local box = tab:AddLeftGroupbox("General", { Text = "General" })
```

## Flags

Controls are stored in the parent's `Objects` table by flag. Give every saved control a stable, unique flag. Without one, the flag is derived from the text and a counter, so renaming a label or reordering controls breaks saved configs.

## Proxies

The library returns **userdata proxies**, not tables, so `type(Fire)` is `"userdata"`.

- `control.Value` and other properties read and write options. Assignments schedule a refresh but **don't** fire the callback.
- Use `:Set(value)` when you want the callback to run.
- `window:PrintAll()` / `control:PrintAll()` lists every method and property.
- Prefer direct property access over the generated `Get...` helpers, which error on `false` values.
