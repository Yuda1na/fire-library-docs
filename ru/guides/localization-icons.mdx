## Переводы

Передайте `Translations` с ключами по языку. Строка заменяет `Text`; таблица устанавливает именованные поля.

```lua
tab:AddButton({ Text = "Save", Translations = { EN = "Save", RU = "Сохранить" } })
```

Язык окна нормализуется в две заглавные буквы (`"ru"` становится `"RU"`).

## Иконки

`Icon` принимает:

- Встроенные имена: `Home`, `Cog`, `Save`, `Trash`, ...
- Имена Lucide: `l://circle-arrow-left`
- Asset ID: `123456` или `rbxassetid://123456`
- URL изображений (скачиваются и кэшируются; нужны файловые и asset API)
