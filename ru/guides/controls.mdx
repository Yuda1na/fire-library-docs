## Общие опции

| Опция | Назначение |
| --- | --- |
| `Text` | Метка |
| `Value` | Начальное значение. `Default` переопределяет его при создании. |
| `Callback` | Срабатывает при изменении или клике |
| `Visible`, `Disabled` | Видимость и взаимодействие |
| `Tooltip`, `DisabledTooltip` | Текст при наведении |
| `Order` | Позиция в родителе |
| `Translations` | Текст на разных языках. См. [Локализация](/ru/guides/localization-icons). |
| `NoConfigs` | Исключить из сохраняемых конфигов (привязанные keybind все равно сохраняются) |

У каждого элемента управления также есть `New...` и короткие алиасы.
