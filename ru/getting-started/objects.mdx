Каждый метод создания принимает `(options)` или `(flag, options)`. Флаг означает ID элемента внутри родителя.

```lua
local window = Fire:Window({ Text = "Test", Keybind = Enum.KeyCode.RightShift })
local tab = window:AddTab("Main", { Text = "Main" })
local box = tab:AddLeftGroupbox("General", { Text = "General" })
```

## Флаги

Элементы хранятся в таблице `Objects` родителя по флагу. Каждому сохраняемому элементу задавай стабильный уникальный флаг. Без него флаг генерируется из текста и счетчика, так что переименование подписи или изменение порядка сломает сохраненные конфиги.

## Прокси

Библиотека возвращает **userdata proxy**, не таблицы, поэтому `type(Fire)` возвращает `"userdata"`.

- `control.Value` и другие свойства читают и записывают опции. Присвоение планирует обновление, но **не** вызывает callback.
- Используйте `:Set(value)`, если нужно, чтобы callback сработал.
- `window:PrintAll()` / `control:PrintAll()` выводят все методы и свойства.
- Предпочитай прямой доступ к свойствам вместо сгенерированных `Get...` хелперов, которые падают на значении `false`.
