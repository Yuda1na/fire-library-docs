## `Invalid request return`

Официальный `Loader.lua` собирает нерабочие GitHub URL. Используйте прямую загрузку из раздела [Установка](/ru/getting-started/installation).

## Окно не появляется

- Проверьте первую ошибку в консоли.
- Убедитесь, что скрипт выполняется на клиенте.
- Нажмите keybind окна (по умолчанию `LeftAlt`).
- `Fire:Window()` ждет инициализации настроек; если там ошибка, ничего не вернется.

## Dropdown показывает неверные варианты

Используйте `Values`, а не `Options`. См. [Dropdown](/ru/guides/dropdowns).

## Конфиги не сохраняются

В executor отсутствует функция для работы с файлами. Список см. в разделе [Темы и конфиги](/ru/guides/themes-configs).

## `type(Fire)` не `table`

Это нормально. Библиотека возвращает userdata proxy. См. [Объекты и флаги](/ru/getting-started/objects).
