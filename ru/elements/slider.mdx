---

Выбирает число между `Min` и `Max`.

```lua
local amount = box:AddSlider("Amount", {
    Text = "Amount",
    Min = 0, Max = 100, Step = 5, Value = 50,
    Format = "/",
    Callback = function(value) print(value) end,
})
amount:Set(75)
```

| Опция | Назначение |
| --- | --- |
| `Min`, `Max` | Диапазон. Алиасы: `Minimum`, `Maximum`. Должны отличаться. |
| `Step` | Шаг. `0` делает его непрерывным. |
| `Format` | Строка формата отображения или функция (см. ниже) |
| `AllowSetValue` | Правый клик или двойной клик для ввода значения |
| `BypassSetValue` | Введенные значения игнорируют проверки диапазона и шага |
| `Styled`, `Compact`, `ShowCompactValue` | Отображение |

## Форматы

`.` `%` `.%` `.1%` `.2%` `/` `//` `/%` `a` `+` `$` `e` `x` `,`

- `.%` трактует `1` как 100%. `%` показывает raw-значение со знаком процента.
- Некоторые форматы делят на `Max` или `Max - Min`.
- Функция получает slider и возвращает текст для отображения.

<Warning>
  `:Set(value)` не обрезает значение. Проверяйте внешний ввод самостоятельно.
</Warning>
